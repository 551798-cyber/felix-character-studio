# Felix — Character Studio

Интерактивный экран персонажа: причёски, цвета волос и глаз, одежда и снаряжение. Оригинальная версия со старым гардеробом.

## Сайт

https://551798-cyber.github.io/felix-character-studio/

## Локальный запуск

Нужны Node.js 22 и Python 3.

```sh
npm ci
npm test
npm run build
npm start
```

Открыть http://127.0.0.1:4173.

## Структура

- `src/` — React, стили, логика персонажа и звук.
- `dist/assets/` — иллюстрации, шрифт, музыка и фоновые частицы.
- `scripts/build.mjs` — сборка через esbuild.
- `scripts/prepare-mobile-art.py` — уменьшенные копии PNG для небольших экранов (Pillow). После замены исходных картинок запустить скрипт и добавить обновлённую папку `dist/assets/compact/` в коммит.
- `tests/` — проверки смены экипировки и независимости музыки от звуков интерфейса.

## Публикация

Изменения в `main` автоматически проходят проверки, собираются и публикуются через GitHub Pages. Статус доступен во вкладке Actions.

Для возврата к исходному опубликованному виду используйте тег `original-v1` либо отмените нужный коммит через `git revert` и отправьте результат в `main`.

## Поведение

Волосы синхронизируются между портретом и фигурой. Одежда меняется только на фигуре. Перчатки и катаны снимаются в рюкзак. Кнопка Music включает и выключает фоновую музыку; звуки интерфейса продолжают работать после первого нажатия.

На телефонах сохраняется вся настольная композиция: она помещается в окно с сохранением пропорций и увеличивается при повороте. Масштабирование жестом не отключено. При начальной ширине окна до 1024 px используются уменьшенные копии рисунков; остальные варианты внешности и одежды загружаются при выборе. Начальная загрузка ждёт только видимые рисунки и маски. Если они не загрузились за 15 секунд, доступны повторная попытка и продолжение с частично загруженной сценой. Шрифт и фоновое видео не блокируют открытие.

Сцена масштабируется через CSS `zoom`, а не внешний `transform: scale`. Это важно для WebKit: в Safari 26.2, Responsive Design Mode, 430×932 при DPR 3 вкладка Layers показывала 1,28 ГБ для прежнего варианта и 41,36 МБ после замены на `zoom` (13 слоёв в обоих случаях). Это измерение графических слоёв в настольном Safari, не всей памяти браузера и не тест на физическом iPhone. Не возвращать внешний `transform` без повторной проверки расхода памяти.

Внутри `.stage` используется `text-size-adjust: auto` (включая префикс `-webkit-`). В старых версиях iOS WebKit значения `100%` и `none` могут отменять масштабирование шрифта через `zoom`: картинки уменьшаются, а текст остаётся огромным ([WebKit #293617](https://bugs.webkit.org/show_bug.cgi?id=293617)). Поэтому нельзя наследовать корневое значение `100%` внутри сцены или заменять его на `none`. Мета-тег viewport с `width=device-width, initial-scale=1` сохраняется; пользовательское увеличение жестом разрешено.


Контрольная отметка `iphone-working-2026-09-25` сохраняет версию, в которой пользователь подтвердил корректное отображение на iPhone. Последующие исправления не меняют масштабирование сцены и текста.

При смене причёски/цвета прежние волосы сохраняются до загрузки и декодирования PNG для портрета и фигуры. Оба вида переключаются вместе; устаревшие результаты быстрых нажатий игнорируются. При ошибке остаётся прежняя причёска и предлагается повторить выбор. Все варианты заранее не монтируются, чтобы сохранить экономию памяти на телефонах.

После первого жеста сайт задаёт `navigator.audioSession.type = 'playback'`, если браузер поддерживает этот API. Это отделяет режим воспроизведения эффектов на iPhone от состояния музыкального HTML-плеера ([WebKit #251532](https://bugs.webkit.org/show_bug.cgi?id=251532)). Кнопка Music управляет только музыкальным файлом; громкость эффектов и их аудиоконтекст не отключаются. На браузерах без Audio Session API остаётся обычный Web Audio. Проверки с задержанными картинками и тесты звуковой логики не заменяют проверку слышимости на физическом iPhone.


Поворачиваемые слои волос на фигуре, катан, перчаток и деталей глаз используют размеры исходного макета в CSS px с переставленными осями. Здесь нельзя возвращать `100cqw` / `100cqh`: эти слои должны проходить тот же единственный `zoom`, что и тело, без дополнительного расчёта по уже уменьшенному контейнеру. При изменении геометрии проверять отношение размеров и совпадение центров рамки и повёрнутого слоя на масштабах 0.13, 0.25, 0.5 и 1. На 2026-09-25 такая проверка прошла для обеих светлых причёсок, катан и перчаток в настольном Safari и встроенном браузере; конкретный iPhone со скриншота для прямого теста недоступен.
