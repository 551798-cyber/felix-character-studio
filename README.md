# Felix — Character Studio

Интерактивный экран персонажа: причёски, цвета волос и глаз, одежда и снаряжение. Оригинальная версия со старым гардеробом.

## Сайт

https://551798-cyber.github.io/felix-character-studio/

## Локальный запуск

Нужны Node.js 22 и Python 3.

```sh
npm ci
npm test
npm run build
npm start
```

Открыть http://127.0.0.1:4173.

## Структура

- `src/` — React, стили, логика персонажа и звук.
- `dist/assets/` — иллюстрации, шрифт, музыка и фоновые частицы.
- `scripts/build.mjs` — сборка через esbuild.
- `scripts/prepare-mobile-art.py` — уменьшенные копии PNG для небольших экранов (Pillow). После замены исходных картинок запустить скрипт и добавить обновлённую папку `dist/assets/compact/` в коммит.
- `tests/` — проверки смены экипировки и независимости музыки от звуков интерфейса.

## Публикация

Изменения в `main` автоматически проходят проверки, собираются и публикуются через GitHub Pages. Статус доступен во вкладке Actions.

Для возврата к исходному опубликованному виду используйте тег `original-v1` либо отмените нужный коммит через `git revert` и отправьте результат в `main`.

## Поведение

Волосы синхронизируются между портретом и фигурой. Одежда меняется только на фигуре. Перчатки и катаны снимаются в рюкзак. Кнопка Music включает и выключает фоновую музыку; звуки интерфейса продолжают работать после первого нажатия.

На телефонах сохраняется вся настольная композиция: она помещается в окно с сохранением пропорций и увеличивается при повороте. Масштабирование жестом не отключено. При начальной ширине окна до 1024 px используются уменьшенные копии рисунков; остальные варианты внешности и одежды загружаются при выборе. Начальная загрузка ждёт только видимые рисунки и маски. Если они не загрузились за 15 секунд, доступны повторная попытка и продолжение с частично загруженной сценой. Шрифт и фоновое видео не блокируют открытие.
